# ORR IMS — standards and templates

**Draft open-source guidance for implementers developing their own management
systems.** This repository focuses on three areas:

1. **ORR IMS definitions and standards:** the learning framework, original internal
   requirements and documentation rules.
2. **Templates:** reusable document types, adoption guidance and clearly fictional
   examples for a bounded concern-to-decision-to-outcome workflow.
3. **Protective governance:** licensing, attribution, source/rights records,
   publication limitations, accepted risks and reporting arrangements.

Compilation and application design led by
[Edward Wee](https://www.linkedin.com/in/edwardbhwee/).
This credit does not claim authorship of ISO standards, IOGP/IPIECA publications
or ORCA. See [AUTHORS](AUTHORS.md) and [SOURCES](SOURCES.md).
